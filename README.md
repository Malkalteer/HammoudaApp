# نظام إدارة المشتركين وفواتير الكهرباء

نظام بديل لملف Excel، مبني بـ React (الواجهة) + Express (السيرفر) + MongoDB (قاعدة البيانات).

## المزايا المطبّقة
- إضافة/حذف/بحث عن المشتركين، مع رقم التابلو.
- تسجيل تأشيرة أسبوعية جديدة → يُنشئ فاتورة تلقائيًا (الاستهلاك = الحالية − السابقة).
- الرصيد غير المسدد يُرحَّل تلقائيًا للأسبوع القادم (يدعم الدفع الجزئي).
- طباعة إيصال بحجم طابعة حرارية 80mm.
- **صفحة القطع**: اختيار مشتركين من القائمة الرئيسية وإرسالهم لصفحة يراها عامل القطع والوصل، مع زر "تم الدفع - وصل" لإعادة التوصيل.
- استيراد بيانات المشتركين دفعة واحدة من ملف Excel القديم (`Main` sheet).
- يعمل على الإنترنت، بحيث يفتحه أي عدد من الأجهزة في نفس اللحظة دون أي تعارض أو قفل ملفات.

---

## 1) التشغيل محليًا للتجربة

### قاعدة البيانات (MongoDB Atlas - مجاني)
1. أنشئ حساب على https://www.mongodb.com/cloud/atlas
2. أنشئ Cluster مجاني (Shared M0)
3. أنشئ مستخدم قاعدة بيانات، واحصل على رابط الاتصال (Connection String)
4. اسمح بالوصول من أي عنوان IP (Network Access > Add IP Address > Allow from anywhere) لتسهيل الاستخدام من المكتب

### الباك إند (Backend)
```bash
cd backend
cp .env.example .env
# افتح .env وضع رابط MongoDB الحقيقي في MONGO_URI
npm install
npm run dev
```
سيعمل على: http://localhost:5000

### الفرونت إند (Frontend)
```bash
cd frontend
npm install
npm run dev
```
سيعمل على: http://localhost:3000

---

## 2) النشر على الإنترنت (خطوات مبسّطة)

### الباك إند → Render.com (مجاني للبداية)
1. ارفع مجلد `backend` إلى مستودع GitHub جديد
2. من Render: New > Web Service > اربط المستودع
3. Build Command: `npm install` — Start Command: `npm start`
4. أضف متغير البيئة `MONGO_URI` بنفس القيمة من Atlas
5. بعد النشر ستحصل على رابط مثل: `https://your-app.onrender.com`

### الفرونت إند → Vercel.com (مجاني)
1. ارفع مجلد `frontend` لمستودع GitHub (أو نفس المستودع في مجلد فرعي)
2. من Vercel: Add New Project > اختر المستودع
3. أضف متغير بيئة: `VITE_API_URL` = `https://your-app.onrender.com/api`
4. Deploy — ستحصل على رابط عام يمكن فتحه من أي جهاز/متصفح

بعد ذلك، افتح الرابط من الجهازين (أو أي جهاز جديد) وسيعملان على نفس البيانات لحظيًا دون أي تعارض.

---

## 3) الاستيراد من ملف Excel القديم
1. افتح رابط البرنامج > اضغط "استيراد من Excel"
2. اختر ملف `.xlsm` أو `.xlsx` الذي يحوي شيت باسم **Main** بنفس أعمدة ملفك الحالي
3. اضغط "بدء الاستيراد" — سيُنشئ كل المشتركين ورصيدهم الحالي تلقائيًا
4. ⚠️ افعل هذا مرة واحدة فقط عند بدء التشغيل، لتفادي تكرار المشتركين

إذا اختلفت أسماء الأعمدة عن الموجودة في `backend/routes/import.js` (داخل `HEADER_MAP`)، عدّلها هناك لتطابق ملفك بالضبط.

---

## 4) ملاحظات مهمة قبل الاستخدام الفعلي
- **سعر الوحدة**: كل مشترك له حقل `unitPrice` (افتراضيًا 1، أي أن التأشيرة تمثل المبلغ مباشرة). إن كان لديك سعر ثابت للوحدة، عدّله لكل مشترك أو اجعله ثابتًا في الكود.
- **الأمان**: هذه نسخة أولية (MVP) بدون نظام تسجيل دخول/صلاحيات مستخدمين. قبل الاستخدام الفعلي في العمل، يُنصح بإضافة صفحة تسجيل دخول بسيطة حتى لا يستطيع أي شخص لديه الرابط الوصول للبيانات.
- **النسخ الاحتياطي**: فعّل النسخ الاحتياطي التلقائي من إعدادات MongoDB Atlas.
